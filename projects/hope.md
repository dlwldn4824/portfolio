### 소원 H.O.P.E 창의보조공학 경진대회 — 왜 또박또박인가
- 또박또박의 본질은 “치료사를 대체하는 AI”가 아니라, **치료실 밖 166시간**에 객관적 피드백이 없는 아동·보호자를 돕는 **보조 도구**다.
- 게임형 연습(몬스터 대결·피치·짝맞추기) + Speech Coach/PCC + 보호자 리포트로, 임상 전문가가 없는 가정 환경에서도 **연습 동기와 피드백 루프**를 보조한다.
- 보조공학 심사가 묻는 “장애·재활 현장의 실질적 보조인가?”에 대해, Pain(대기·비용·가정 무피드백·일반화 실패)을 데이터로 먼저 증명한 뒤 기능을 매핑한 점이 차별점이다.

### HUSS AI 경진대회 장려상 — 왜 또박또박인가
- HUSS AI는 **사회문제 × AI**를 묻는다. 또박또박은 학령기 조음음운장애·치료 대기·연 치료비 부담 등 공공·언론·논문 근거로 문제를 정의했다.
- 장려상 이후에도 결과에 안주하지 않고 **최우수팀 인터뷰·심사기준 재분석**을 수행 → “기술보다 문제 정의·사용자 검증”이 완성도를 가른다는 회고로 이어졌다.
- 산출물: 제안서(`정융고능팀_proposal`) + 웹 프로토타입 + `research/problem-validation` 텍스트마이닝 파이프라인.

## 한눈에 (문제 → AI → 수치)
| | |
|--|--|
| **문제** | 가정 연습에 객관 발음 피드백 공백 (치료실 ~1% 시간) |
| **AI** | Wav2Vec2-CTC·음소 정렬·PCC/PER · STT 보정으로 오류가 사라지지 않게 |
| **수치** | 문제검증→기능 매핑 · 소원 H.O.P.E 창의보조공학·HUSS 장려×2 · 임상 PCC 향상은 후속 검증 |

## 왜 이 문제를 선택했는가
주 168시간 중 치료실은 약 1%(~2시간)에 불과하고, 나머지 가정 시간은 객관적 발음 피드백이 거의 없다.  
학령기 조음음운장애 규모·대기(최대 수년)·비용 Pain이 명확해, **가정 기반 보조공학 + AI 피드백**으로 풀 문제로 선택했다.

## 실제 문제로 어떻게 검증했는가
- 공공데이터 · 뉴스 · 논문 수집 → TF-IDF / LDA / 공출현 네트워크 (`research/problem-validation`)
- Pain Point: **비용 · 대기 · 가정 피드백 공백 · 일반화 실패**
- Pain → HOPE 기능 매핑 (게임 연습, 즉각 피드백, 보호자 리포트)
- HUSS 심사 후 최우수팀 인터뷰·기준 재분석으로 검증 루프를 한 번 더 돌림

## 솔루션
- **아동**: 게임형 조음 연습 (몬스터·피치·짝맞추기 등)
- **피드백**: Speech Coach / PCC 기반 발음·음운 피드백
- **보호자**: 진행·숙제·리포트
- **설계 스택 후보**: Wav2Vec2-XLSR · OpenSMILE · g2pK · FastAPI · Firebase · RN  
- **구현 데모**: React+TS+Vite 웹 + Speech Coach API 연동

## 효과 · 정량 지표
- **수상**: 소원 H.O.P.E 창의보조공학 경진대회 장려상 + HUSS AI 경진대회 장려상 (이중 인정)
- 문제검증 → 기능 매핑의 **연구–제품 연결**을 문서로 재현 가능
- 사회지표(치료실 비중 ~1%, 가정 무피드백 구조 등)를 제안·심사 근거로 사용  
  ※ 제품 KPI(임상 PCC 향상 등)는 프로토타입 단계로 후속 검증 과제
