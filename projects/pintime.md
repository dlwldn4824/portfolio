# PinTime

## 카테고리
- **주 카테고리**: AI × 서비스 · Agent 워크플로
- **부 카테고리**: Web · 프론트
- **연결 레포**: `dlwldn4824/pintime`
- **한 줄**: 조율·확정·캘린더까지 잇는 AI 일정 에이전트 프로토타입

> GitHub: https://github.com/dlwldn4824/pintime  
> 라이브: https://pintime.vercel.app · 피치: https://pintime.vercel.app/pitch.html

## 왜 이 문제를 선택했는가
밴드·팀·해커톤 일정을 잡으며 When2Meet식 “방마다 표 다시 채우기”와 확정 후 캘린더 재등록으로 **흐름이 끊기는** 문제를 겪음. 기능을 더하기보다 **끊긴 핸드오프**를 잇는 것이 본질이라고 정의.

## 실제 문제로 어떻게 검증했는가
동작하는 프론트 프로토타입을 배포해 대화 입력 → 후보 → 확정 → 같은 저장소 캘린더 등록 루프를 시연.  
제품 지표 후보: 추천 횟수보다 **확정까지 대화 수 · 충돌 재발률 · 외부 도구 전달 성공**.

## 솔루션
- 규칙 파이프라인(`agentParse`): 참여자·하드/소프트 제약 파싱 → 휴리스틱 후보 → 사람 승인
- 조율 방·링크 참여·JSON 페이로드로 방 간 일정 이어 붙이기
- 설계 원칙: *끊기는 곳을 잇고, 확정 한 번이면 캘린더까지*
